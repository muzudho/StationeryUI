# StationeryUI — 文房具UI

文房具をモチーフにした GUI ライブラリーと、  
その画面配置を設計する「スタイル設定エディター」のプロジェクトです。  
MonoGame を使い、設定・編集・制作などのツール向けのクロスプラットフォーム GUI を目指しています。
