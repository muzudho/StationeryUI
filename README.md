# StationeryUI — 文房具UI

MonoGameでPC向けの設定画面・編集画面を作るための、文房具をモチーフにしたGUIライブラリーです。日本語IMEの入力接続、文字編集、アプリに合わせたテーマを提供します。MITライセンス。

初期版 **0.1.1**。公開APIは今後変更する可能性があります。
