# Contributing

小さな変更と再現可能な検証を歓迎します。大きなAPI変更は、用途と呼び出し例をIssueで共有してください。

- コアへMonoGame/Windows依存を追加しないでください。
- 入力・状態管理の変更では、文字列・選択範囲・操作順序を使った回帰検査を追加します。
- IMEの不具合報告には、OS、IME名、.NET/MonoGame版、DesktopGL等のバックエンド、DPI、再現操作を記載します。実際の個人情報や秘密を入力例に含めないでください。
- 新しいコントロールにはアクセシブルな名前、キーボード操作、テーマの適用方針を用意します。
- ソース・画像・フォント等の出所とライセンスを明示します。

初期の0.x版ではAPIを変更する可能性があります。破壊的変更はリリースノートへ移行例を記載し、両利用アプリで確認します。公開した同じパッケージ版は差し替えません。

検査コマンドは[開発者向け案内](README.md)を参照してください。OS/IMEの実機確認は自動テスト成功と区別して記録します。
