# NuGet.org へ公開する

文房具 UI のパッケージを NuGet.org に登録する、公開担当者向けの入口です。

## 初めて公開する方

- [本人が準備すること](account-setup.md)：アカウント作成、２段階認証、作業分担。
- [v0.2.0 を公開する手順](publish-v0.2.0.md)：Web 画面からアップロードし、公開結果を確認。

## 継続公開を整備する方
