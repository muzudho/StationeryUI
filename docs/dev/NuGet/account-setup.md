# 本人が準備すること

初回は Web 画面から公開する方法をおすすめします。API キーを作成せずに進められます。確認日：2026-09-22。

## むずでょさんにお願いすること

1. [NuGet.org のサインイン](https://www.nuget.org/users/account/LogOn)を開き、Microsoft アカウントでログインする。
2. 案内に従い、２段階認証を設定する。すでに設定済みなら、その認証でログインする。
3. NuGet.org のアカウントがなければ、公開用ユーザー名を決めて登録する。ユーザー名は後から変更できないため、公開して使い続けられる名前にする。
4. メール確認などの案内が表示された場合は完了する。
5. [公開手順](publish-v0.2.0.md)に沿って、用意済みの３パッケージをアップロードする。

アカウントと２段階認証の条件は[公式の個人アカウント手順](https://learn.microsoft.com/en-us/nuget/nuget-org/individual-accounts)を参照してください。

## 作業の分担

| 担当 | 作業 |
|---|---|
| 本人 | ログイン、本人確認、ユーザー名の決定、Web 画面でのアップロードと Submit |
| Codex | パッケージ作成、版・依存関係・テストの検証、公開後の参照確認とドキュメント更新 |

v0.2.0 のパッケージ作成と GitHub Releases での配布は完了しています。公開前の検証結果は[配布記録](../distribution/library-v0.2.0.md)を参照してください。

Codex へ伝えるのは「アカウントを作れた」「どのパッケージを公開できた」と公開ページの URL で十分です。問題が起きたら、秘密情報を除いたエラーメッセージを知らせてください。パスワード、認証コード、回復コード、API キーはチャットやリポジトリーに載せません。
