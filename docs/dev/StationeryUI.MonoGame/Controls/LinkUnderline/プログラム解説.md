# Link Underline

クリックで非同期アクションを開始する、文房具 UI のアンダーライン部品です。

- 実行中は二重起動を受け付けません。
- 開始から 0.1 秒を超えても処理中なら、リンク右端にスピナーを表示します。
- `Cancel()` は `CancellationToken` でアクションへ中断を要求します。アクションが完了するまでは再実行できません。
- 中断要求後は、アクションが正常終了した場合も成功扱いにはせず、`中断しました。状態が完全に更新されていない可能性があります。` と表示します。

`LinkUnderline` は `IUnderline` を所有し、状態に応じた色で描画する UI コンポーネントです。`GoScreenRenderer` には依存しません。実際の下線描画は `StationeryDrawingTools` へ委譲します。

- `drawText`: 日本語ラベルを描画する処理
- `drawSpinner`: 指定座標にスピナーを描画する処理

ホストが持つフォント、SpriteBatch、仮想座標変換は `drawText`、`drawSpinner`、`StationeryDrawingTools` 側で扱います。

同期的に画面遷移・選択を行う既存リンクには、スピナーを持たない `Bounds` と `UpdatePointer(point)` を設定してから `Draw(surface)` を使えます。選択状態は `SetSelected` で指定できます。

## 使用例

```csharp
// linkUnderline と controller は画面のフィールドとして保持する。
linkUnderline.Bounds = bounds;
if (clickedThisFrame && linkUnderline.IsHit(mousePoint))
    controller.TryStart(token => LoadAsync(token), nowSeconds);

controller.Update();
linkUnderline.Draw(
    "LOAD", mousePoint, controller, nowSeconds,
    drawText, drawSpinner, surface);
```

この断片の `clickedThisFrame` はホストの押下エッジ判定です。
`linkUnderline` は `new LinkUnderline(new RoundUnderline())` で生成し、
描画コールバック、時刻、非同期処理もホストから渡します。

画面を閉じる際には `Cancel()` を呼び、中断完了後にエラー状態を描画してください。
