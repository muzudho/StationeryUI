# Section Label のプログラム解説

`SectionLabelComponent` は、区画に付ける見出しラベルです。

- `TargetSectionBounds` がラベルを付ける対象区画、`Bounds` がラベル自身の位置とサイズです。
- `CreateVertical` または `CreateHorizontal` の生成時に両方のBoundsを確定します。
- 文字、色、水平／垂直方向も生成時に確定し、読み取り専用で所有します。
- `Direction` が `Vertical` の場合は区画の左側へ表示します。
- 縦方向へ文字が収まらない場合は、幅を広げて最大2行の横書きにします。
- `Direction` が `Horizontal` の場合は区画の上側へ表示します。
- `Draw` は位置やサイズを計算せず、生成時に確定した `Bounds` と共通の `StationeryDrawingTools` だけを使います。
- SectionLabel専用の描画コールバックレコードは持ちません。
- `EnableVisibilityPin` を呼ぶと、任意機能の表示ピンが付きます。`IsPinned` が表示状態、`VisibilityPinBounds` がピン自身の領域です。
- ピンのヒット判定は `IsVisibilityPinHit` に集約し、ピンを外した状態では斜線付きの抜けたピンとして描画します。
- `CreateVerticalAt` は、移動アニメーション中など、呼び出し側で補間済みの `Bounds` を使って縦ラベルを生成する入口です。
