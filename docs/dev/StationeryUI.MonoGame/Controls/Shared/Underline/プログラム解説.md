# Underline のプログラム解説

アンダーラインは画面ごとのインスタンスとして保持します。共通の基底は `AbstractUnderline` です。

- `RoundUnderline` は丸み付きの下線を描画します。
- `SquareUnderline` は角が四角い下線を描画します。
- `StationeryDrawingTools` が描画先を抽象化します。各 Underline は Bounds、太さ、色、オフセットを自分で保持し、rendererには依存しません。

Link Underline、テキスト入力用の Underline、罫線状の複数行 Underline は、この共通形状を使えます。
