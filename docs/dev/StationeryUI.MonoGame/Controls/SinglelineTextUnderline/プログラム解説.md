# Singleline Text Underline

[SinglelineTextUnderlineComponent](../../../../../src/StationeryUI.MonoGame/Controls/SinglelineTextUnderline/SinglelineTextUnderlineComponent.cs) は単一行入力欄の下線を描画します。
`Bounds` を設定し、`SetEditing` と `UpdatePointer` で状態を更新し、`Draw(surface)` を呼びます。
編集時は緑、ホバー時は紫、通常時は落ち着いた青灰色です。

文字編集は [TextBoxController](../../../../../src/StationeryUI.MonoGame/Controls/TextUnderlineController.cs) などが担当します。
本文、キャレット、選択範囲、IME 未確定文字列の表示はホストの責務です。
GTP オプション用の `TextInputDialog` は利用アプリに残した画面で、この共通部品には含みません。
