# 自前テキストボックスのアルゴリズム

## 役割と構成

[TextUnderlineController.cs](../../../../src/StationeryUI.MonoGame/Controls/TextUnderlineController.cs) の `TextBoxController` は、MonoGame 上で使う単一行・複数行テキストボックスの**編集状態と入力操作**を担当する。
描画そのもの、マウス座標からキャレット位置への変換、各画面の編集開始・確定・取消しは画面側が担当する。

```text
マウス・キーボード・文字入力
            ↓
   TextBoxController
  （文字列、キャレット、選択、履歴）
            ↓
  各画面のセッション状態
            ↓
 ホストの描画処理（選択範囲とキャレットを描画）
```

画面側は、クリック位置を文字列の測定幅から `caretIndex` に換算して、
`BeginMouseSelection` / `UpdateMouseSelection` に渡す。これによりコントローラーは
フォントやレイアウトを知らずに共通の編集操作を提供できる。

## 保持する編集状態

| 状態 | 内容 |
| --- | --- |
| `Text` | 現在の文字列 |
| `CaretIndex` | 文字と文字の間を示す位置。常に `0..Text.Length` に丸める |
| `SelectionAnchor` | 選択を始めた側の位置。`CaretIndex` との差が選択範囲になる |
| `IsMouseSelecting` | マウスボタンを押したままドラッグ選択中か |
| undo / redo 履歴 | 文字列、キャレット、選択アンカーの組 |

選択範囲はアンカーとキャレットの大小に依存しない。
`SelectionStart = Min(anchor, caret)`、`SelectionLength = Abs(anchor - caret)` として求めるため、
左向き・右向きのドラッグや Shift+矢印を同じ仕組みで扱える。

## 実装済み機能の棚卸し

### 文字編集

- 単一文字入力。制御文字は無視し、最大文字数を超える入力は拒否する。
- 選択範囲がある状態での入力は、選択文字列を置換する。
- Backspace（キャレットの左）と Delete（キャレットの右）。選択中は範囲削除する。
- 単一行モードの貼り付け時は改行を除去し、必要なら呼び出し元の文字フィルターを適用する。
- 貼り付け・選択置換も最大文字数に収まる部分だけを挿入する。

数値欄などでは、画面側が `TryInputCharacter` を呼ぶ前の判定と貼り付けフィルターに数字などの制約を与える。

### キャレットと選択

- Left / Right でキャレット移動、Home / End で先頭・末尾へ移動。
- Shift+Left / Right / Home / End で選択を拡張または縮小する。
- マウスクリックでキャレットを置き、押下中のドラッグで選択範囲を更新する。
- Shift+クリックでは既存の選択アンカーを保って選択を拡張する。
- 同じ欄を 0.36 秒以内にダブルクリックすると全文選択する。
- Ctrl+A で全文選択する。

文字列の変更、単独のキャレット移動、`Begin`、`Clear` の際には、必要に応じて選択を解除する。

### クリップボード

- Ctrl+C: 選択文字列をコピーする。
- Ctrl+X: コピーに成功した場合だけ選択文字列を切り取る。
- Ctrl+V: クリップボードの文字列を貼り付ける。
- `allowClipboardExport` を `false` にすると、コピーと切り取りだけを無効化できる。

OS ごとの差異は `IClipboardService` に隠している。取得・設定に失敗した場合でも、編集状態を壊さない。

### Undo / Redo

- Ctrl+Z で undo、Ctrl+Y で redo。
- 文字入力、貼り付け、切り取り、Backspace、Delete の直前に、文字列・キャレット・選択アンカーをスナップショットとして保存する。
- 新しい編集を始めると redo 履歴を破棄する。
- 履歴は最大 100 件に制限する。
- `Begin` と `Clear` は新しい編集セッションとして履歴を消去する。

キャレット移動や選択だけは履歴に積まない。undo/redo 後はマウスドラッグ中の状態を終了する。

### キーリピート

Left、Right、Backspace、Delete、Ctrl+Z、Ctrl+Y は押し続けても操作できる。
最初の入力直後に 0.42 秒待ち、その後は 0.055 秒間隔で繰り返す。
キーを離すと待ち時間を初期値へ戻す。フレームが一時的に遅れても、カウントダウンを補正して安定した反復になるようにしている。

### 編集の終了通知

- 単一行では Enter が `TextBoxKeyboardAction.Commit` を返す。
- `HandleKeyboard(..., multiline: true)` では Enter が改行を挿入し、Ctrl+Enter が確定する。
- Escape は `TextBoxKeyboardAction.Cancel` を返す。

確定時に保存するか、取消時に元の値へ戻すかは画面側の責務である。

## 主な呼び出し手順

1. 編集開始時に `Begin(text, caretIndex)` を呼ぶ。
2. 毎フレーム `HandleKeyboard` を呼び、必要なら `TryInputCharacter` で文字入力を渡す。
3. マウス押下時は画面側で座標をキャレット位置に変換し、`BeginMouseSelection` を呼ぶ。ドラッグ中は `UpdateMouseSelection`、ボタンを離したら `EndMouseSelection` を呼ぶ。
4. `Text`、`CaretIndex`、`SelectionStart`、`SelectionLength` を画面セッションと描画へ反映する。
5. `Commit` または `Cancel` を受け取った画面側が編集セッションを終了する。

## 現在の制約

- 複数行モードでは改行を保持する。上下方向の行間キャレット移動はこのコントローラーでは扱わない。
- キャレット位置と最大長は UTF-16 のインデックスで表す。左右移動・削除では書記素境界を使い、文字入力ではサロゲートペアを組み立てる。
- 画面側がマウス座標をキャレット位置へ変換し、選択背景とキャレットを描画する必要がある。

## コアの編集モデルとの関係

このクラスは既存の MonoGame 画面向けの入力コントローラーである。
OS・MonoGame 非依存の [UnderlineTextEditor](../../../../src/StationeryUI/Text/UnderlineTextEditor.cs) と
[TextInputSession](../../../../src/StationeryUI/Text/TextInputSession.cs) も提供している。
IME の未確定文字列の取得・描画はホストとプラットフォームサービスが担当する。
