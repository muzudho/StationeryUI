# Stationery UI の描画境界

共通コントロールの描画窓口は [StationeryDrawingTools](../../../src/StationeryUI.MonoGame/StationeryDrawingTools.cs) です。
旧文書の `StationeryDrawingContext` に相当します。アプリの画面クラスへ依存せず、
[ScreenCanvas](../../../src/StationeryUI.MonoGame/ScreenCanvas.cs) と文字ラスタライザーを介して図形・文字・選択範囲を描きます。

- `StationeryUI` は OS・MonoGame 非依存の編集、入力、テーマなどのモデルを持ちます。
- `StationeryUI.MonoGame` はコントロールの描画、仮想座標変換、MonoGame の入力接続を持ちます。
- `StationeryUI.Windows` は Windows の IME、クリップボード、文字ラスタライズを提供します。

描画の開始・終了は `Begin` / `End` で対応させます。内部で開始・終了するポップアップには
外側で重ねて `Begin` しないでください。`End` は描画後の動的文字テクスチャの解放も担当します。
共通の `Theme` は描画窓口で指定できますが、対応範囲は部品ごとに異なります。
ボタンは個別テーマと色の上書きにも対応します。

碁石、対局結果、背景、画面別付箋配置などは利用アプリの責務です。
部品ごとの説明は [解説一覧](../control-guide.md) を参照してください。
