# 配布に関する資料

文房具 UI とエディターに共通する配布手順・確認事項をまとめます。公開済みの各版の結果は[版別の開発・配布記録](../version/README.md)から探してください。

- [文房具UIエディターのリリース手順](ui-editor-release.md)：準備、ZIP 作成、動作確認、GitHub 公開、公開後の確認。
- [NuGet.org への公開手順](../NuGet/README.md)：アカウントの準備と登録手続き。
- [配布で忘れないこと](notes.md)：版番号、署名、同梱物、文字コード、自動検査の範囲。

文房具 UI ライブラリーとエディターは別の成果物です。エディターは Windows x64 用 ZIP、ライブラリーは NuGet パッケージとして配布するため、それぞれの手順と版を確認してください。

参照元は、別リポジトリーの `D:\github.com\muzudho\CircleSpaceCoordinator\Docs\Dev\配布` にある `README.md`、`バージョン管理.md`、`リリース手順.md` です。ダウンロード案内、第三者 DLL の扱い、新しいフォルダーでの発行・展開確認を取り入れています。同リポジトリー専用の証明書作成・信頼登録、エンジン同梱、利用者設定の移行コマンドは、このプロジェクトの手順には含めません。

追記時には確認日、対象バージョン、参照元、実際に確認した結果と未検証事項を残してください。
