# ドキュメント作成のガイドライン

- トップの README は役割別のナビゲーションとし、利用者向けの案内を先に置きます。
- `docs/user/` には製品の説明・操作・設定を置きます。
- `docs/dev/` には組み込み・実装・ビルド・検証・公開手順を置きます。利用者が開発者向け資料を読まなくても使えるようにします。
- ユースケースは登場人物を定義し、使われる場面に沿ったシナリオにします。[既存のユースケース](../user/style-settings/use-case.md)を参考にしてください。
- ファイルを移動したら、参照元のリンクと見出しアンカーも更新し、トップの README から辿れることを確認します。
