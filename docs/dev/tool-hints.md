# ツールヒントの接続

## C# で説明を接続する

```csharp
var export = ui.AddButton("export", bounds, "エクスポート", Export);
export.ToolHint = "現在の設計を新しい JSON ファイルに出力します。";

// ui.Update の後に、インスペクターパネル内の表示へ反映する。
toolHint.Label = ui.HoveredToolHint
    ?? "コントロールにマウスを合わせると説明を表示します。";
```

多くのコントロールをまとめて管理する場合は `StationeryUiHost.ToolHintProvider` に説明を返す関数を設定できます。各要素の `ToolHint` を優先し、設定されていない場合に Provider を使用します。無効なボタンでもホバーの説明は取得できます。

複数のホストを使う場合は、マウスが乗っている領域とモーダルの有無に応じて表示元を選びます。プレビューなど実操作を受け付けない領域にも、「クリックで編集対象を選ぶ」のように、その領域で可能な操作を説明します。

キーボード操作の可否や入力エラーを、ホバー説明だけに依存させないでください。項目名・単位・エラー表示を残し、詳細な操作方法はユーザーズガイドからも確認できるようにします。
