## 初回実装で調整した点

1. 既存画面の入力契約を保つため、きふわらべのWin32/SDL合成監視を `WindowsCompositionObserver` としてWindowsパッケージへ抽出した。アプリは通知形式の変換だけを持つ。新規ホスト・サークルは `ITextInputService` を使用する。
2. 既存のキーリピート・複数行編集を担う `TextBoxController` はMonoGameパッケージ内に維持した。新規の単一行モデルとのAPI統合は実機検証後の改善対象。
3. アプリ固有の付箋配置・背景・対局表示はきふわらべに残した。共通ライブラリーへ囲碁や会場編集の業務ロジックは入れない。
4. 既存プロジェクトの参照窓口を残して移行範囲を抑えた。共通部品のコピーは削除し、バージョン指定のPackageReferenceから供給する。
5. OS/バックエンド追加、画面読み上げ連携、デザイナー、全コントロール共通の高度なレイアウトシステムは後続とする。初期版の範囲をREADMEに明記した。

## 中断・再開

1. 3リポジトリーの `git status` と、この文書・検証記録を確認する。利用者が編集しているチャットなどを巻き戻さない。
2. GitHub公開とCIの実施結果が未記録なら確認する。既存リポジトリー・タグ・Releaseを二重作成しない。
3. まず `validation.md` の手動IME検証を実施する。その後、既存画面の新しいセッションAPIへの統合とDPI変換を改善する。
4. NuGet.orgへ公開する場合はアカウントと認証方法を確認する。認証情報をコミットしない。公開版を同じ版番号で上書きしない。
5. 各アプリのローカルフィードを削除するのは、公開ソースだけでクリーン復元できることを確認してからにする。
