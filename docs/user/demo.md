# デモの操作

文房具 UI のデモを起動済みの方への操作案内です。スタイル設定エディターとは別のアプリです。

名前欄・メモ欄に日本語を入力できます。Tab／Shift+Tab で欄を移動し、Ctrl+A/C/X/V/Z/Y で選択・コピー・切り取り・貼り付け・取り消し・やり直しができます。ボタンで明暗テーマと表示倍率を切り替えられます。

入力欄にマウスを合わせると `EDIT` バッジが現れます。「ダイアログで編集するテキスト」の `POPUP` を押すと別の編集画面が開き、「保存して閉じる」で反映、「キャンセル」で変更を破棄します。

トップページの［リンク：レイアウトデモ］から、ボックスレイアウトとグリッドレイアウトのデモへ進めます。左側ではボックスの 24px の余白、右側では 3 行 × 3 列のグリッドを確認できます。右側のセルにはボックスと 2 行 × 2 列のグリッドが入れ子になっており、複数行・複数列にまたがる配置も見られます。

セルにマウスを合わせると、下側の高さ 80px のインスペクターパネルに説明が出ます。ウィンドウのサイズを変更すると各領域が伸縮します。［← トップページへ］で戻れます。リンクは Tab で選んで Enter でも操作できます。

３つのページは共通の `pageDock`（`dockLayout`）を使い、直下の `body` を中央、`inspectorPanel` を下端へ配置します。トップ・レイアウトデモの下端は80px、スプリットペーンデモは0pxです。F12 のツリーでも「ページ → 本文／インスペクター」と分かれて表示されます。本文のグリッドや余白は `body` に設定しています。
