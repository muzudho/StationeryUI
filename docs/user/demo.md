# デモの操作

文房具 UI のデモを起動済みの方への操作案内です。文房具UIエディターとは別のアプリです。

デモ画面で **F12** を押すと、文房具UIエディターの読取画面が開き、実行中の文房具の階層・配置・詳細を調べられます。**Ctrl＋F12** で同じエディターを編集モードに切り替え、デモが現在読み込んでいる文房具UIファイルを開きます。左右どちらの Ctrl キーでも操作できます。編集内容は元ファイルへ自動保存され、デモにも自動反映されます（自動反映を無効にしている場合は F5 で再読み込み）。エディターが見つからない環境では従来の F12 開発者ウィンドウを使います。

リポジトリーではデモのビルド時にエディターもビルドされます。別途配置したエディターを使う場合は、環境変数 `STATIONERYUI_EDITOR_PATH` に `StationeryUIEditor.exe` のパスを指定してください。指定がなければデモと同じフォルダーの実行ファイル、ビルド時の実行ファイルの順に探します。起動できない場合はデモのタイトルバーに理由を表示します。

名前欄・メモ欄に日本語を入力できます。Tab／Shift+Tab で欄を移動し、Ctrl+A/C/X/V/Z/Y で選択・コピー・切り取り・貼り付け・取り消し・やり直しができます。ボタンで明暗テーマと表示倍率を切り替えられます。

入力欄にマウスを合わせると `EDIT` バッジが現れます。「ダイアログで編集するテキスト」の `POPUP` を押すと別の編集画面が開き、「保存して閉じる」で反映、「キャンセル」で変更を破棄します。

トップページの［リンク：レイアウトデモ］から、ボックスレイアウトとグリッドレイアウトのデモへ進めます。左側ではボックスの 24px の余白、右側では 3 行 × 3 列のグリッドを確認できます。右側のセルにはボックスと 2 行 × 2 列のグリッドが入れ子になっており、複数行・複数列にまたがる配置も見られます。

トップページの［リンク：ページ内の部分切替］から、部分切替デモへ進めます。［概要を表示］と［詳細を表示］を押すと右側の内容だけが変わり、見出し・リンク・下部の説明は残ります。切替先と起動時の選択は文房具UIファイルに設定されています。詳しくは[ページ内の部分切替](partial-navigation.md)を参照してください。

セルにマウスを合わせると、下側の高さ 80px のインスペクターパネルに説明が出ます。ウィンドウのサイズを変更すると各領域が伸縮します。［← トップページへ］で戻れます。リンクは Tab で選んで Enter でも操作できます。

トップとレイアウトページは `pageDock`、スプリットページは `pageDockFullscreen`（どちらも `dockLayout`）を使い、直下の `body` を中央、`inspectorPanel` を下端へ配置します。トップ・レイアウトデモの下端は80px、スプリットペーンデモは0pxです。F12 のツリーでも「ページ → 本文／インスペクター」と分かれて表示されます。本文のグリッドや余白は `body` に設定しています。
