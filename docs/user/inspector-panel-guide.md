# インスペクターパネルとツールヒント欄

文房具 UI の作業画面では、画面の下端に高さ **80px**、画面いっぱいの横幅を持つ「インスペクターパネル」を置きます。その中の「ツールヒント欄」に、マウスカーソルを合わせたコントロールの説明を表示します。

## 画面の作り方

- 先に下端の 80px を確保し、その上の領域へ編集欄・ツリー・プレビューなどを配置します。パネルを編集内容の上へ重ねません。
- 80px はビューポートのピクセル数です。UI の拡大率に比例して高さを変えず、ウィンドウサイズが変わったら位置と横幅を更新します。
- 常設の長い操作説明はツールヒントへ移します。コントロール名、入力項目名、単位、編集中の対象など、操作対象を見分けるためのラベルは残します。
- 説明は「押すと何が起きるか」「何を入力するか」「単位や条件」を短い文で書きます。例：「px は固定サイズ、rate は残りの領域を分け合う比です。」
- 無効なコントロールにも説明を出します。例：「先にフォルダーを選択してください。」無効になっている理由と、使えるようにする操作を伝えます。
- カーソルを外したら以前の説明を消し、案内の初期表示へ戻します。モーダルダイアログを開いている間は、背面の説明を出しません。

入力エラー、重複 Id、警告、保存結果などは一時的なホバー説明とは別に扱います。重要な結果がホバーで消えないよう、パネルの別行や入力ダイアログ内へ表示します。スタイル設計ツールでは、上の56pxをツールヒント、下の24pxを状態・結果の欄にしています。

## スタイル設定

作業ページを定義する際は `work-page-layout` の `inspectorHeight` を `"80px"` とし、`bindings` で本文とは別の inspector 用モデルを指定できます。本文の余白でパネルの横幅を狭めないようにします。具体的な定義は [スタイル設定のページレイアウト](stationery-style-settings.md) を参照してください。

操作説明の内容はアプリ側で設定します。配置用 JSON だけでは C# の操作内容を推測できません。

## C# で説明を接続する

```csharp
var export = ui.AddButton("export", bounds, "エクスポート", Export);
export.ToolHint = "現在の設計を新しい JSON ファイルに出力します。";

// ui.Update の後に、インスペクターパネル内の表示へ反映する。
toolHint.Label = ui.HoveredToolHint
    ?? "コントロールにマウスを合わせると説明を表示します。";
```

多くのコントロールをまとめて管理する場合は `StationeryUiHost.ToolHintProvider` に説明を返す関数を設定できます。各要素の `ToolHint` を優先し、設定されていない場合に Provider を使用します。無効なボタンでもホバーの説明は取得できます。

複数のホストを使う場合は、マウスが乗っている領域とモーダルの有無に応じて表示元を選びます。プレビューなど実操作を受け付けない領域にも、「クリックで編集対象を選ぶ」のように、その領域で可能な操作を説明します。

キーボード操作の可否や入力エラーを、ホバー説明だけに依存させないでください。項目名・単位・エラー表示を残し、詳細な操作方法はユーザーズガイドからも確認できるようにします。
