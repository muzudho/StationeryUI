# これはどのような製品か

この［文房具ＵＩ］（StationeryUI）リポジトリーでは、２つのプロダクトを配布しています。  
* `GUIライブラリー` - 文房具がモチーフ。NuGet パッケージで配布。デモ有り。
* `スタイル・デザイナー` - その画面配置を編集するWindows アプリケーション。

MonoGame フレームワークで作られています。一部、Windows に依存しています。  

| 製品 | 役割 | 手にするもの |
| --- | --- | --- |
| スタイル設定エディター | ツリーとプレビューで行高・列幅・余白などを調整する | 起動して使うアプリと、保存した `*.stationery-style.json` |
| 文房具 UI | 入力欄・ボタン・ツリーなど、アプリの画面を構成する | 開発担当者がアプリへ接続するライブラリー |

エディターで保存した JSON を開発担当者や AI へ渡し、「この配置で画面を作って」と依頼できます。スタイル設定に対応済みのアプリでは、設定を編集して見た目を調整できます。ボタンを押したときの動作や画面遷移の実装は、開発担当者の仕事です。

## できることと対象範囲

エディターでは主に `layouts` の配置設定を編集します。`models` と `bindings` は参照でき、既存ファイルの情報は保持しますが、すべての画面構造を GUI だけで作れるわけではありません。C# の自動生成は行いません。編集範囲は[エディターの使い方](style-designer.md)を参照してください。

配布されているエディターは Windows x64 向けです。クロスプラットフォーム GUI はプロジェクトの目標で、macOS・Linux 向けエディターの配布や全 OS での動作確認を意味しません。

エディターとライブラリーは版を別々に管理しています。エディターの ZIP とライブラリーのパッケージは別の成果物です。
