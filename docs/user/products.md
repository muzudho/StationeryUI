# これはどのような製品か

この［文房具ＵＩ］（StationeryUI）リポジトリーでは、２つのプロダクトを配布しています。  
* `GUIライブラリー` - 文房具がモチーフ。NuGet パッケージで配布。デモ有り。
* `文房具UIエディター` - その画面配置やページを編集する Windows アプリケーション。

MonoGame フレームワークで作られています。一部、Windows に依存しています。  

## 構成物

* `アプリケーション設定ファイル` - 例えば `*.stationery-config.json` といった名前のファイルですが、必須ではありません。
* `スタイル設定ファイル` - 例えば `*.stationery-ui.json` といった名前のファイルです。

## できることと対象範囲

エディターでは主に `layouts` の配置設定を編集します。`models` と `bindings` は参照でき、既存ファイルの情報は保持しますが、すべての画面構造を GUI だけで作れるわけではありません。C# の自動生成は行いません。編集範囲は[エディターの使い方](ui-editor.md)を参照してください。

配布されているエディターは Windows x64 向けです。クロスプラットフォーム GUI はプロジェクトの目標で、macOS・Linux 向けエディターの配布や全 OS での動作確認を意味しません。

エディターとライブラリーは版を別々に管理しています。エディターの ZIP とライブラリーのパッケージは別の成果物です。
