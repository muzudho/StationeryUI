# スタイルデザイナー v0.3.0

通常の利用には、Assets の **Windows x64 用 ZIP** をダウンロードしてください。

この版では、文房具 UI フレームワークとレイアウトデザイナーの版番号を `0.3.0` に統一しました。レイアウトデモでは不要な `box` 中間ノードをなくし、モデルへ `boxLayout` を直接関連付けています。

## ダウンロード

- Windows x64 用 ZIP：GitHub Release の Assets
- SHA-256：同じ Release の `SHA256SUMS.txt`

ZIP を展開し、`StationeryUI.StyleDesigner/StationeryUI.StyleDesigner.exe` を起動してください。.NET 8.0.31 ランタイムを同梱しています。

## 対象範囲

Windows x64 を対象とします。macOS、Linux、Windows ARM64、.NET ランタイム未同梱の環境は今回の検証対象外です。
