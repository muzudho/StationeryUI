# スタイル設計ツール

文房具 UI で作る画面のプランを GUI で組み立て、`*.stationery-style.json` を出力する独立アプリ。
出力した JSON を AI コーディングへ渡し、「この設計で C# の画面を作って」と依頼する。
既存アプリや既存設定ファイルの直接編集、C# の生成は行わない。

## 使い方

1. 横のセル数（列数）と縦のセル数（行数）を入力し、「表を作る／更新」を押す。最初の版は各 1～8 セル。
2. 表の上で各列の幅、左で各行の高さを指定する。数値は入力欄、単位は `rate`／`px` の切り替えボタンで指定する。
3. 中央のセルをクリックし、下の種類ボタンで文房具を選ぶ。空き領域・ボタン・テキスト入力・説明テキスト・ページリンク・ツリーを選べる。表示名も入力できる。
4. サイズのプレビューを確認する。中央は編集しやすい等間隔の表、下のプレビューは指定した行列のサイズ配分を表す。下の図は横・縦をそれぞれ表示領域へ縮めているため、実際の画面の縦横比を表すものではない。
5. 存在するフォルダー内の新しい出力先を指定し、「エクスポート」を押す。拡張子は `.stationery-style.json`。既存ファイルは上書きしない。

`1.5rate` は数値欄に `1.5`、単位に `rate` を指定する。px は固定サイズ、rate は残りの領域を分け合う比。
負数、数値欄への単位入力、全行／全列がゼロになる設定は出力できず、画面にエラーを表示する。
表を縮める操作は範囲外のセルを削除するため、同じセル数で更新をもう一度押すと確定する。
Tab で入力欄やボタンへ移動し、Enter／Space でボタンを操作できる。明暗テーマも切り替えられる。

## AI に渡す設計図

モデルの Id は `cellR1C1` のように位置から自動生成される。人が Id を入力する必要はない。
`models` に文房具の種類と `label`、`layouts` に行列のサイズ、`bindings` にセルへの配置を出力する。
`label` は設計用の表示名。現行のスタイルローダーはこれを描画へ自動反映しないため、AI が C# のラベルや初期テキストとして接続する。
ボタンの動作、リンクの遷移先、ツリーの内容などは、JSON と一緒に AI へ別途指示する。

この版は一つのページ・一つのフローティングレイアウトの設計が対象。複数ページ、スプリットペーン、既存 JSON の読み込み、設計途中の再開は未対応。
作業中のプランはメモリー上にあるため、終了前にエクスポートする。

## 起動と配布

ソースからの起動：

```powershell
dotnet run --project samples/StationeryUI.StyleDesigner -c Release
```

リリース用の出力：

```powershell
dotnet publish samples/StationeryUI.StyleDesigner -c Release --self-contained false -o artifacts/release/style-designer
```

出力フォルダー全体を配布し、`StationeryUI.StyleDesigner.exe` から起動する。Windows 用の .NET 8 Desktop Runtime が必要。
設計ツールは文房具 UI の DLL を利用するが、文房具 UI の NuGet パッケージに設計ツールは含めない。
