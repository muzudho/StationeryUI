# これはいつどのように使われるか

## 導入の意義 — レイアウトの調整を人間に委譲する

* `白田さん` - 人間
* `TaroMax` - AI エージェント
 
白田さんが、TaroMax にコーディングを依頼しました。  

TaroMax は、完成したプロダクトを人間に渡しました。  

白田さんが実物の画面を見ながら「この列を少し広く」「余白をもう少し小さく」と  
調整したくなることがあります。  

### Case 1: 白田さんが直接スタイルを編集する仕組みがなければ  

TaroMax にコーディングを再依頼する必要があります。  
再依頼の結果が、白田さんの希望通りになるとは限りません。  

### Case 2: もし、この［文房具ＵＩのスタイル設定］機能があれば  

TaroMax は C# ソースコードに［文房具ＵＩ］を実装し、  
［文房具Ｉｄ］、［挙動］、［スタイル設定ファイルへの連携］を実装し、  
配置位置等の設定は、人間が変更できるよう、［スタイル設定ファイル］へ切り出します。  

TaroMax は、「ここからの見た目の微調整は、白田さんがやってね」と引き渡します。  

白田さんは、このリポジトリーにある［スタイル設定エディター］を使って、  
GUI を見ながら寸法・比率・余白等を編集します。  
［オートリロード］機能を有効にしておけば、実行中のアプリに即座に反映されます。  
編集した内容は `*.stationery-style.json` に保存されます。  

［スタイル設定エディター］でできないことは、引き続き TaroMax に再依頼します。  

──そんなツールを目指します。  

## 構成物

* `アプリケーション設定ファイル` - 例えば `*.stationery-config.json` といった名前のファイルですが、必須ではありません。
* `スタイル設定ファイル` - 例えば `*.stationery-style.json` といった名前のファイルです。
