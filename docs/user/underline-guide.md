# 下線付きテキストの見分け方

文房具 UI の下線付きテキストは、編集やページ移動などの操作ができる目印です。
何が起きるかは、**テキストの色**と、マウスカーソルを合わせたときに現れる**角丸バッジ**で見分けます。

## 三種類のバッジ

| バッジ | クリックしたときの動作 | 例 |
|---|---|---|
| `Edit` | その場でテキストや値を編集する | 名前欄、メモ欄 |
| `Popup` | ポップアップやダイアログを開く | 別の編集画面で値を変更する項目 |
| `Move` | 別のページへ移動する | デモページへのリンク、元のページへ戻るリンク |

ダイアログ内で編集する項目でも、まず別の画面を開く操作なので `Popup` です。
`Move` はページ移動を表し、部品をドラッグして移動する意味ではありません。

## テキストの色

- **ページ移動のリンク**：テキストとアンダーラインを同じ色にします。
- **編集できるテキスト**：ライトモードでは黒系、ダークモードでは白系を基本にします。ポップアップで編集する値も、この読みやすい文字色を基本にします。

編集欄では、フォーカスによって下線の色が変わっても、文字は基本の読みやすい色を保ちます。
色だけで判断しづらいときは、カーソルを合わせてバッジの文字を確認できます。
バッジは操作内容を説明する表示で、下線付きテキストと別の操作ボタンではありません。
