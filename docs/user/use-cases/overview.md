# これはいつどのように使われるか

## 画面レイアウトしよう！

* `白田さん` - 人間
* `TaroMax` - AI エージェント

白田さんは、デスクトップ・アプリケーションを開発しています。  

```plaintext
白田さん＞　TaroMax、画面を作ってくれだぜ（＾▽＾）

TaroMax ＞　はい、できます［ー＿ー］
```

TaroMax は、完成したプロダクトを人間に渡しました。  
白田さんは実物の画面を確認します。  

```plaintext
白田さん＞　うーん、この列を少し広く。余白をもう少し小さくしてくれだぜ（＾▽＾）

TaroMax ＞　はい、できました［ー＿ー］

白田さん＞　できてないぜ、もう一回、この列を少し広く、余白をもう少し小さくしてくれだぜ（＾～＾）

TaroMax ＞　はい、できました［ー＿ー］

白田さん＞　うーん、できてないなあ（＾～＾）
```


### [Case 1] 白田さんが直接スタイルを編集できる仕組みがなければ  

```plaintext
白田さん＞　うーん、自分でやった方が早いかな、ソースコードを見せてくれだぜ（＾～＾）

TaroMax ＞　はい、Screen.cs に書いてあります。［ー＿ー］

白田さん＞　うわあ、人間が編集しきれるボリュームじゃないなあ（＾～＾）
```


### [Case 2] もし、この［文房具ＵＩ］を使って実装していれば  

```plaintext
白田さん＞　うーん、自分でやった方が早いかな（＾～＾）

TaroMax ＞　ここからの見た目の微調整は、
　　　　　　［スタイルデザイナー］を使って白田さんがやってね［ー＿ー］
```

* ［F12］キーで［開発者ウィンドウ］を開いて、［指でつまむ］アイコンボタンをクリック。
* 画面上の［文房具ＵＩ］をクリックして、［開発者ウィンドウ］で［文房具レイアウトパス］を確認。

```plaintxt
白田さん＞　このアプリケーションの［文房具スタイル設定ファイル］は、どこにあるんだぜ（＾～＾）？

TaroMax ＞　`App_Data/demo.stationery-style.json` にあります［ー＿ー］
```

* 別途［スタイルデザイナー］アプリケーションを起動。
* ［スタイルデザイナー］で、`App_Data/demo.stationery-style.json` を開く。
* ［スタイルデザイナー］の［レイアウトツリー］から、目的の［文房具レイアウトパス］を選択。
* 入力欄で、寸法・比率・余白等を編集。
* ［オートセーブ］なので、そのまま［スタイルデザイナー］を閉じる。

──そんなツールを目指します。
