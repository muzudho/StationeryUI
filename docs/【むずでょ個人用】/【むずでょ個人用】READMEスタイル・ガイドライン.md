# 【むずでょ個人用】READMEスタイル・ガイドライン

## ［ドキュメントの最初のページ］のスタイル・ガイドライン

ドキュメントの最初のページは、［ナビゲーション］という働きを持たせます。  
［どのような役割の人］が読むのかによって、ドキュメントへのリンクを用意してください。  

例えば：  
* `利用者` - 配布物を利用したい人
* `開発者` - 成果物の改善に貢献したい人

［利用者］向けのドキュメントには、［開発者］向けの手順や実装の詳細は書かない。  
［開発者］向けのドキュメントには、［利用者］向けの手順や配布物の使い方は書かない。  
［ドキュメントの最初のページ］には、［利用者向けのドキュメント］と［開発者向けのドキュメント］へのリンクを用意する。  

そして、［利用者］は［開発者向けドキュメント］の内容を知らなくてもよいようにします。  
［開発者］には、［利用者向けドキュメント］の内容が役に立ちます。  

ディレクトリー階層の例です。  
* `{リポジトリー}`
	* `docs`
		* `dev` - ここに［開発者向けドキュメント］を置く。
		* `user` - ここに［利用者向けドキュメント］を置く。

👆　ディレクトリー名、ファイル名は PascalCase にする場合もあります。

## ［利用者］向けのドキュメントのスタイル・ガイドライン

例えば、以下のリンクを置きます。  

* `これはいつどのように使われるか` - `docs/user/{プロダクト名}/use-case.md` へのリンク
* `これはどのような製品か`
