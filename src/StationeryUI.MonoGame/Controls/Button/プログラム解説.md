# Button のプログラム解説

[Button](Button.cs) は位置とサイズ `Bounds`、表示文字 `Label`、文字倍率 `LabelScale`、有効状態 `IsEnabled` を所有します。
`IsHit(point)` は有効な場合だけ領域内の点に反応します。クリックによる操作の実行はホストが担当します。

`Draw(mousePoint, surface)` は `StationeryDrawingTools` で影・背景・枠・文字を描き、ポインター状態も更新します。
`IsPressed`、`IsSelected`、`IsFocused` はホストが設定します。
配色は部品の `Theme`、未指定なら `surface.Theme` を使います。
`FillColor` と `PointerOverFillColor` で通常時・ホバー時の背景色を上書きできます
（無効・押下・選択状態にはテーマの状態色を使います）。

`AutoExpandLabel` は既定で有効です。高さから読みやすい文字倍率を求め、指定倍率と比較したうえで領域に収めます。
無効にすると指定倍率を基準にします。`AccessibleName` は `Label` を返します。
