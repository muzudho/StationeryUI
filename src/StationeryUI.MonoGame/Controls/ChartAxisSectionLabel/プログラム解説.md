# Chart Axis Section Label のプログラム解説

`ChartAxisSectionLabelComponent` は、チャートの軸名、表示ピン、目盛りラベルをひとまとまりで所有する文房具UIです。

- `Bounds` は透明な軸名ラベルの位置とサイズです。
- `Side` は目盛りをプロットの左側または右側のどちらへ置くかを表します。
- `DrawHeader` は軸名と表示ピンを描画します。ラベル面は透明で、抜けた状態でも再表示用のピンと軸名が残ります。
- `DrawAxisLabels` はプロット領域から目盛り位置を一括計算します。`EVEN` や `50%` をrendererで個別に位置調整しません。
- `IsVisibilityPinHit` は内部の `SectionLabelComponent` にヒット判定を委譲します。
