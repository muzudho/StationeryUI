# Multiline Text Underline

[MultilineTextUnderline](MultilineTextUnderline.cs) は複数行入力欄の罫線を描く部品です。
本文、選択、キャレット、IME 未確定文字、モーダルの確定・取消しはホストが扱います。

`Bounds` で領域を指定し、`SetEditing` と `UpdatePointer` で状態を更新して `Draw(surface)` を呼びます。
`LineHeight` は正の行高、`BaselineOffset` は本文上端からベースラインまでの距離です。
本文と同じフォントの測定値を設定してください。`HorizontalInset` と `TextTopInset` は余白です。
最初の罫線は `Bounds.Y + TextTopInset + BaselineOffset` に置き、行高ずつ進めます。

ホストは罫線を先に描き、その上へ本文を描画します。縮小時にも線を見せる場合は、
仮想画面の縮小率を考慮して `Underline.Thickness` を設定します。
SGF への反映などの保存処理はこの部品に含みません。
