# Popup Number Underline

[PopupNumberUnderline](PopupNumberUnderline.cs) は整数入力ポップアップの描画・ヒット判定・
文字幅に基づくキャレット位置の計算を担当します。
`Draw` にはタイトル、編集中の文字列、キャレット、選択範囲、メッセージ、表示オプションを渡します。
`StationeryDrawingTools` を受け取る描画入口は実マウス座標を仮想座標へ変換し、内部で `Begin` / `End` を呼びます。
ヒット判定やキャレット位置の計算へ渡す点は、ホスト側で仮想座標へ変換します。

`OkButton`、`CancelButton`、`ClearButton` と `SpinButtons` を公開します。
操作を検出して値へ反映するのはホストです。
編集は [TextBoxController](../TextUnderlineController.cs) に委譲できます。

入力文字の制限と整数としての検証は分けます。例えば数字と負号だけを受け付けても `--1` は整数ではありません。
ホストは確定時に `int.TryParse` と最小・最大値を確認し、失敗時はメッセージを渡して編集を継続します。
成功時の下書き更新、永続化、取消時の破棄もホストの責務です。
